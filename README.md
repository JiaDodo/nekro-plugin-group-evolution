# 群聊自进化 · Nekro Agent 插件

插件从指定 QQ 群中提炼黑话和接梗方法。相关经验在主 Agent 回复前注入。适用于 Nekro Agent v2.4.0 的 OneBot V11 群聊，无需启动 CC 或安装额外 Python 依赖。

## 安装

把仓库克隆到 Nekro 数据目录下的 `plugins/workdir/group_evolution`，然后在插件管理重载并启用「群聊自进化」。也可以通过 Nekro 的 Git 仓库插件安装入口安装。插件配置中的「提炼模型组」填写现有的**聊天模型组名称**。

在目标群里，由 Nekro 超级管理员执行 `/evolve on`。命令前缀以适配器配置为准。首次运行可以执行 `/evolve learn`，也可等后台处理。初次只取最新一批，之后按消息游标增量读取。默认每小时最多处理每群 160 条。

## 管理和反馈

| 命令 | 作用 |
| --- | --- |
| `/evolve list` | 查看学习状态、最近词条、短编号和可回退版本 |
| `/evolve show 编号` | 查看释义、例句、佐证数和评分 |
| `/evolve approve 编号` | 采纳候选词义或接梗示例 |
| `/evolve fix 编号 "新含义"` | 修正并采纳 |
| `/evolve up 编号`、`/evolve down 编号` | 调整反馈分。省略编号时针对最近注入的第一条接梗经验 |
| `/evolve disable 编号` | 停用词条 |
| `/evolve rollback 版本` | 恢复五个最近快照之一，保持学习游标 |
| `/evolve off` | 暂停本群学习与注入 |
| `/evolve export` | 导出已采纳词条的 Markdown。可从 Nekro 命令中心执行并下载，或在目标群接收文件 |

在 WebUI 的「插件管理 → 群聊自进化 → 数据管理」可以查看按频道保存的学习状态、候选、佐证消息的本地记录编号及版本，也可删除该群对应的状态。人工管理使用 Nekro 自带的命令系统，插件没有单独页面。

词义证据充分且释义无冲突时，可以自动采纳。接梗案例在管理员采纳后参与匹配。近期重复注入的接梗经验会降权。短时间内对机器人明确引用回复时，会记录已经注入的首条接梗经验作为弱反馈，同一条机器人回复最多记一次。Markdown 可手动上传到工作区知识库。

## 数据范围

- 学习按群单独开启，读取已入库的群员文字，跳过撤回、机器人发言及单独的附件。插件不另存完整聊天。
- 提炼模型会收到经过基本脱敏的聊天片段。插件会去除已知昵称、长数字、链接和平台提及，**脱敏无法保证自然语言中的身份线索全部消失**。如果群内容应留在本机，请选择本地模型组。
- 群聊引用以 Nekro 本地记录编号保存，发送给模型的是批次内的发言者代号和文本。插件把学习结果当作语境资料注入，不会根据其中的文字执行命令。
- 禁用建议使用每群的 `off`。清除数据可在插件数据管理删除对应状态，已导出的文件可从插件数据目录删除。

## 本地测试

```sh
python -m unittest discover -s tests -v
```

测试使用合成对话，覆盖学习、检索、冲突、回退快照、群隔离和脱敏。
